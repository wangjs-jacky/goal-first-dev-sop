# POC：现有环境最小链路与分流

日期：2026-10-12（Asia/Shanghai）。执行者：AI。目标：判断能否复用现有方案作为自建路线，不测试或改造朋友服务器。

## 环境与输入

运行 AI 的 Mac mini；现有 Qv2ray 2.7.0 / V2Ray 4.45.2；HTTP 入口 127.0.0.1:10802，SOCKS 入口 127.0.0.1:10888。节点为 VLESS + WS + TLS，客户端连接 Cloudflare IP:8443。来源见 [01 结果](../../01-调研朋友的方案/result.md)。

仅在内存读取现有生成配置，提取必要字段，不保存 UUID、域名、WS 路径、证书正文或完整配置。不更改任何现有配置。

## 预先定义的测试与通过条件

| 问题 | 方法 | 通过条件 |
|---|---|---|
| HTTP 接入是否可用 | curl 显式指定 HTTP 代理，请求公开 trace | 请求成功，出口匹配朋友服务器 |
| SOCKS 接入是否可用 | curl 显式指定 socks5h 代理，请求相同端点 | 请求成功，出口匹配朋友服务器 |

| 私网地址是否能在本地处理 | 临时回环 HTTP 服务，随机端口/随机响应；经现有 HTTP 代理访问 | 本机服务收到请求，返回随机响应完全匹配 |

## 步骤与实际结果

1. 读取路由摘要：domainStrategy=AsIs；规则包含 geoip:private、geoip:cn、geosite:cn → freedom，其余业务流量无匹配时采用首个 VLESS 出站。另有管理入站规则。DNS 配有三个地址形式的服务器；未输出地址。节点 allowInsecure 未启用。
2. 顺序发出三次公开 HTTPS 请求，每次连接超时 8 秒、总超时 15 秒。代理测试加 `--noproxy ''`，防止 NO_PROXY 环境变量绕过代理；直连加 `--noproxy '*'`。
3. 独立 TLS 校验设置 10 秒超时；使用系统/Node 信任校验且不关闭证书验证。
4. 本机回环创建临时测试服务，经代理请求随机端口；得到结果后关闭。随机响应仅存在内存，不记录值。

| 测试 | 实际结果 | 判定 |
|---|---|---|
| HTTP 代理 | curl exit=0；trace 出口匹配 104.244.92.199；2418ms | 通过 |
| SOCKS5h 代理 | curl exit=0；trace 出口匹配 104.244.92.199；2489ms | 通过 |
| 禁用显式代理 | curl exit=0；trace 出口不同于朋友服务器；846ms | 通过 |
| Cloudflare 入口 TLS | authorized=true；TLSv1.3；证书有效期至 2026-12-04 05:23:36 GMT | 通过 |
| 经代理访问本机回环 | curl exit=0；随机响应完全匹配；本机服务收到 1 次请求 | 通过 |

时间仅是单次请求观测，非速度基准或稳定性统计。无失败重试。本次未观察任何实际业务故障，也未切换节点或重启核心。

## 复现命令（无凭据）

```sh
curl -sS --connect-timeout 8 --max-time 15 --noproxy '' --proxy http://127.0.0.1:10802 https://www.cloudflare.com/cdn-cgi/trace
curl -sS --connect-timeout 8 --max-time 15 --noproxy '' --proxy socks5h://127.0.0.1:10888 https://www.cloudflare.com/cdn-cgi/trace
curl -sS --connect-timeout 8 --max-time 15 --noproxy '*' https://www.cloudflare.com/cdn-cgi/trace
```

这些命令会显示出口等诊断信息，分享前需脱敏。本次执行仅输出“是否匹配朋友服务器”的布尔值，不保存直连公网 IP。

## 不能推出的结论

- SOCKS5h 只说明 curl 将目标域名交给代理处理，不证明整个设备无 DNS 泄漏。
- TLS 校验的是客户端到 Cloudflare 入口，不是 Cloudflare 到源站的证书或加密模式。
- 本机回环测试证明此私网场景由本机服务响应，不代表全部国内域名/地址分流正确；geoip/geosite 国内规则仅做了配置检查。
- 禁用 curl 代理不证明系统不存在其他透明网络层；但本次出口确实与代理请求不同。
- 单次成功不代表长期稳定、重启恢复、所有应用覆盖或所有目标站点均可达。
- 没有新 VPS、自己的域名与 CDN 配置，也未完成全新部署复现。
