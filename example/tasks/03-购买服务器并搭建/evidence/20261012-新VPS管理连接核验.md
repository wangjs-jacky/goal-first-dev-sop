# 新 VPS 管理连接核验

日期：2026-10-12。范围：仅本任务新购 RackNerd 实例，未修改远端配置。

## 实际执行

1. 从已登录官方客户区进入对应产品、邮件历史，定位该实例的 KVM VPS Login Information；核对 IP 与购买记录一致。
2. SSH BatchMode 测试到达认证阶段，但本机既有公钥未获授权，返回 Permission denied；不是网络超时。
3. 从开通邮件读取该实例 root 密码，仅留在进程内存，传给本机 expect 子进程进行 SSH 认证，不打印或落盘。首次 SSH 按 accept-new 信任并保存主机指纹，后续 StrictHostKeyChecking=yes；尚未通过独立渠道核对指纹。
4. 成功执行只读系统检查；密码不写入 Git，未重置密码或公开凭据。
