# T03 · 购买服务器并搭建

复制下面整段给已打开本仓库的独立 AI。

```text
执行 example 的 T03 搭建。所有路径以仓库根目录为基准。先读取 AGENTS.md、example/problem.template.md、example/README.md、example/tasks/T03-deploy/README.md 和 example/tasks/T02-poc/result.md，必要时引用 T01 的结果。有本任务 result.md 时先读取，避免重复购买或部署。

目标：在属于用户自己的服务器上部署选定服务，并从目标设备完成第一次连接。前置路线未选定时先解决选型，不猜测预算或协议。

开始先补齐真正影响购买的设备、预算和地区要求，给出简短服务器建议及实际费用来源，用户选择并完成付款。已有合适实例就核对后复用，不重复购买。部署前说明本次要改的环境、最小实施步骤、首次连接怎么验证及失败如何恢复。

经授权后逐步完成服务器管理连接、必要初始化、服务安装和客户端连接。每一步结合当前实际系统与版本处理，并解释为什么做；不把调研中的示例命令不加核对直接执行。若 T02 留有必须在自有服务器验证的条件，先验证这些条件再继续；失败时保存结果并回到 T02 调整。修改远程管理入口前保留可用的恢复方式。朋友的服务器不在本任务改动范围内。

将成果保存在 example/tasks/T03-deploy/：result.md 记录选型、费用/续费方式、版本、实际步骤、首次连接结果、恢复方法和遗留问题；部署笔记放 notes/，脱敏验证证据放 evidence/，失败及修复过程放 attempts/。在 README 更新状态、产物索引，追加时间、执行者、进展与反馈。密码、密钥和完整认证配置只通过私密渠道管理，文件只留引用。

完成标准：用户自己的实例可管理，服务已部署，目标设备首次连接和选定目标访问有实际证据。不能连接时报告阻塞或失败，不以安装完成代替连通成功。结束后交回结果路径，建议 T04 做使用验证，不自动执行下一项。
```
