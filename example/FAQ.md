# 追问与回答

记录本需求层面的实际追问；具体 Task 的问答写到该 Task 的 `FAQ.md`。每次回答后由 AI 追加，不需要用户再说“记一下”。

## 2026-10-11 · 追问过程中出现的问题怎么保存？

问题（归纳）：过程中会不断向 AI 提问，希望问题和回答都留下记录。

回答：每次追问回答后，将问题和本轮回答写入所属目录的 `FAQ.md`，并通过需求目录的 `AGENTS.md` 或具体任务的 `index.md` 链接。涉及具体任务就写在该 Task 下；涉及整体需求就写在这里。同一问题的后续追问追加在原条目下，注明日期；尚不能确定的答案标为待验证，之后有新证据再补充更正。

依据：[工作约定](../AGENTS.md)。这是文件记录规则，未涉及服务技术验证。
