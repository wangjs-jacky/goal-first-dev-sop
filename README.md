# Goal-first development SOP

A minimal, auditable workflow: clarify outcomes, reference context, plan small tasks, execute with evidence, and revise from feedback.

Status: **v0.1 draft; not yet validated end to end.** The first case is learning to deploy and understand a personal proxy service, starting with a friend's existing setup and Qv2ray as a research entry point.
